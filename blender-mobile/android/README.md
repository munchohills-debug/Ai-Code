# Android target

This folder is reserved for the Android application project.

Expected output:

- `app-debug.apk` for testing
- `app-release.apk` for sideloading
- `app-release.aab` for Google Play

A real Blender Android build needs the Blender source tree, Android NDK, and all native dependencies compiled for the target ABIs. This repository does not redistribute Blender binaries.
